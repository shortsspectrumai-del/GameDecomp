Console files and support limits

Experimental Ghidra loaders: Switch NSO/NRO, PlayStation 1 PS-X EXE, Game Boy Advance ROM, GameCube/Wii DOL, NES mapper 0 and linear Mega Drive/Genesis ROM. Choose the matching console profile. DOL requires the profile before upload.

PS2/PSP and PS4/PS5 modules may use the generic ELF path; Xbox modules may use the generic PE path when already extracted and readable. This does not establish full console support. SELF, XCI, PFS0, XVD/XVC, disc images and encrypted packages need external extraction. Other raw ROM formats and NES mappers are not supported.

Console results cover static CPU analysis. Target ABI compilation and hardware behavior remain UNKNOWN; PC compilation is never counted as console validation. Assets and complete game projects are not reconstructed.
